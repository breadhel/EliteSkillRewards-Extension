EliteSkillRewards-Extension is an EliteMobs addon created for Minecraft 1.26.1 that allows server administrators to reward players with EliteMobs skill levels and XP using simple commands.

The addon integrates directly with EliteMobs' internal skill system, allowing rewards to work alongside the normal EliteMobs progression system. Players keep EliteMobs' native XP handling, skill progression, level calculations, XP displays, sounds, particles, and level-up effects.

Designed for server events, competitions, giveaways, staff rewards, and custom progression systems, EliteSkillRewards-Extension gives administrators an easy way to control player skill progression without replacing or modifying EliteMobs' existing mechanics.

Commands:
- /emskill add <player> <skill> <levels>
  Gives a player a chosen amount of EliteMobs skill levels.

- /emskill xp <player> <skill> <amount>
  Gives a player a custom amount of EliteMobs skill XP.

Features:
- Supports EliteMobs skills
- Uses EliteMobs' own progression system
- Keeps EliteMobs level-up behaviour
- Includes command tab completion
- Lightweight and simple for server staff
- Useful for events, rewards, and custom server content

Compatibility:
Made for Minecraft 26.1 and EliteMobs 11.x.
May work on Minecraft 1.21.8+ versions, but compatibility may vary depending on EliteMobs updates.
